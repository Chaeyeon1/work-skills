# 고르는 질문 페이지

> 평소의 /질문 은 채팅으로 "~할까요?"를 묻지 않고, 그림으로 고르는 HTML 페이지를 만든다: 질문마다 지금 화면·흐름 그림, 선택지마다 고르면 화면이 어떻게 되는지 미니 화면, 추천안 미리 선택, 메모, 다른 안(직접 적기), 답 복사, 새로고침 유지. 페이지는 점검 스크립트로 확인한 뒤 연다. 여기서는 미니 화면 대신 그 경우의 자료 몇 줄과 선택지별 결과 숫자로 보여 준다.

채팅에 "~할까요?"를 늘어놓지 않는다. 고를 것이 둘 이상이면 이 페이지로 낸다.
`$논의` 는 방법 하나를 비교해 추천하는 것이고, `$질문` 은 사용자가 여러 개를 한꺼번에 고르는 페이지다.

## 1. 질문 고르기

- 사용자 답이 **다음 행동을 바꾸는 것**만 묻는다. 자료에서 확인되는 사실은 묻지 않고 확인해서 적는다.
- 묻기 전에 사실을 먼저 센다(그 경우가 지금 몇 건인지). "아마"로 쓴 선택지는 답을 받아도 뒤집힌다.
- 이미 답한 것은 다시 묻지 않는다. 앞 답의 메모가 질문이면 그것부터 답하고 다음 차수로 묻는다.
- 내가 혼자 정해 버린 것(`→ 지금 0건, 코드는 ○○ 로 처리` 등)도 질문으로 꺼낸다.
- 대상·기간·범위처럼 **요청자에게 물어야 할 것**은 이 페이지로 사용자에게 묻지 말고, 요청자에게 보낼 질문 한 줄로 낸다.

## 2. 질문 파일 쓰기

`.verify/질문_HHMM.json` (git 이 무시하는 폴더, 시각은 `date +%H%M`):

```json
{
  "title": "2단계 전에 정할 것",
  "lead": "무엇을 왜 묻는지 한두 문장",
  "questions": [
    {
      "id": "Q1",
      "title": "취소된 예약은 이용 시간에 어떻게 넣을까?",
      "ctx": "쉬운 말로 상황 한두 문장. 코드 이름은 꼭 필요할 때만 괄호로",
      "table": {"caption": "자료 3줄 (data/rooms.csv:12-14)", "head": ["예약", "방", "시간", "상태"],
                "rows": [["R-101", "A", "2", "완료"], ["R-102", "A", "3", "취소"]], "mark": [[1, 3]]},
      "options": [
        {"key": "A", "label": "아예 세지 않는다", "effect": "합계 47시간 · 영향 3건", "recommended": true},
        {"key": "B", "label": "이용 시간에서 차감", "effect": "합계 41시간 · 영향 3건"}
      ]
    }
  ]
}
```

- **모든 질문에 `table`** — 그 경우가 실제로 나오는 자료 몇 줄(파일:줄), `mark` 로 걸리는 칸을 강조한다.
- **모든 선택지에 `effect`** — 고르면 결과가 어떻게 바뀌나(합계·건수·어느 줄이 빠지나). 두 뜻이 되는 말 대신 숫자로.
- 화면 모양이 바뀌는 선택지면 그 선택지에도 `table` 을 달아 "고르면 이렇게 보인다"를 보인다.
- 추천안 하나에 `"recommended": true`(미리 선택된다). '다른 안(직접 적기)'과 메모 칸은 질문마다 자동으로 붙는다.

## 3. 만들고 보여 주기

```bash
python3 .agents/skills/질문/scripts/question_html.py .verify/질문_HHMM.json   # 없으면 ~/.agents/skills/…
```

→ `view/questions.html`. 보는 법: 새 터미널에서 `python3 -m http.server 8090 --bind 0.0.0.0` (이미 켜 두었으면 그대로) → Browser 탭 PORT 8090, URL `/view/questions.html`.
사용자는 고르고, 아래 상자의 답을 '답 복사'(또는 상자 안 글을 선택해 복사)해서 붙여 넣는다.

채팅에는 질문 수와 무엇을 묻는지 한 줄씩만. 질문 내용을 채팅에 다시 늘어놓지 않는다. 답을 기다리는 동안 질문과 무관한 일은 계속한다.

## 4. 답을 받으면

붙여 넣은 `[… 답]` 블록:
1. **메모부터 읽는다.** 메모에 질문이 있으면 사실을 확인해 먼저 답하고, 남은 판단은 다음 차수 페이지로.
2. 고른 것을 AGENTS '확인 안 된 것' 해당 줄 끝에 `→ 사용자 결정 HH:MM (요청자 미확인)` 으로 달고, NOTES '결정'에 `- HH:MM 고른 것 / 이유(메모) — 출처: HH:MM 나` 한 줄.
3. `질문: HH:MM 고른 것 요약` 으로 커밋한다.

요청자 미확인 결정은 합의 확인이나 결과 메시지의 '제가 정한 것' 묶음에만 넣어 확인받는다.
