# 요청자 답 → 규칙

입력: 사용자가 붙여 넣은 질문과 답. 시각(HH:MM)이 없으면 지금 시각.

1. **원문 남기기.** NOTES.md '요청자 대화' 아래 `- HH:MM Q: … / A: …`. 요약하지 않는다. 숫자·고유명사는 그대로.
2. **규칙 넣기.** 지킬 규칙이 나왔으면 AGENTS.md '확정된 규칙'에 `N) 규칙 — 출처: HH:MM 요청자`. 번호는 이어서.
   - 이미 있는 규칙과 부딪히면 고치지 않는다. 둘 다 보여 주고 사용자에게 묻는다.
   - "보통", "대개", "아마" 로 말한 것은 '확인 안 된 것'으로.
3. **빈틈.** 규칙마다 모르는 경계를 하나씩 '확인 안 된 것'에: 경계값(이상/초과), 빈 값, 기간 경계, 예외 대상, 바뀐 버전, 단위.
4. **몇 건에 걸리나.** 셀 수 있으면 명령을 돌려 건수를 센다. 명령도 같이 보여 준다.

출력은 다섯 줄 안팎: 추가한 규칙, 확인 안 된 것, 걸리는 건수.
요청자가 말하지 않은 숫자·기준은 넣지 않는다.
