# 한 단계 구현

1. AGENTS.md 와 PLAN.md 의 그 단계만 읽는다. 다른 단계는 하지 않는다.
2. 구현 전에 할 일과 건드릴 파일을 두세 줄로. 방법이 둘 이상이면 멈추고 `$논의` 를 제안한다.
3. 구현한다. 판정·계산은 코드로. 규칙을 옮긴 곳에 `# 규칙 N`.
4. 단계의 확인 명령을 실행하고 출력을 그대로 보여 준다. 기대와 다르면 원인을 한 번 확인하고 고친 뒤 같은 명령을 다시.
5. 한 건을 손으로 맞춰 볼 수 있게 입력 한 줄과 기대 출력 한 줄을 골라 `직접 확인:` 으로 칠 명령을 준다.
6. 커밋: `N단계: 무엇 — 확인: 명령 → 결과`.
7. NOTES.md '진행'에 `- HH:MM N단계 · 한 것 · 확인 결과 · 커밋 앞 7자`.
8. 멈춘다. 다음 단계는 사용자가 부를 때.

서버를 띄우는 단계면 0.0.0.0 에 바인딩하고, 띄운 터미널은 그대로 두라고 알려 준다. 포트와 경로를 `직접 확인:` 에.
