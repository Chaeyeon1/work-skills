# 방향 논의 (코드 미생성)

인자: 논의 주제. 사용자가 고민 중인 선택지가 있으면 그것부터.

1. **지금 상황.** 관련 파일·자료를 필요한 만큼만 본다. 코드가 아직 없으면 바로 2.
2. **선택지 비교.**

| | A | B | C |
|---|---|---|---|
| 설명 | | | |
| 확정된 규칙을 지키나 | 규칙 번호로 | | |
| 만드는 데 드는 것 | | | |
| 틀릴 수 있는 곳 | | | |
| 확인 방법 | | | |

3. **추천.** 하나를 고르고 근거를 규칙 번호·자료(파일:줄)로. 재지 않은 것은 [추정].
4. 사용자가 고르면 NOTES.md '결정'에 `- HH:MM 고른 것 / 이유 / 기각한 것과 이유`, 기각한 것은 AGENTS.md '기각한 대안'에도 한 줄.

가장 단순하게 요구를 채우는 안을 늘 후보에 넣는다.
