# 규칙 검사 (고치지 않는다)

1. 작업 폴더에서 점검 스크립트를 실행하고 결과를 보여 준다.
   `bash .agents/skills/검사/scripts/check.sh` (없으면 `bash ~/.agents/skills/검사/scripts/check.sh`)
2. **대조표.** AGENTS.md '확정된 규칙'마다 `| 규칙 | 코드 위치(파일:줄) | 확인 명령 → 결과 | 상태 |`. 확인 명령은 실제로 다시 돌린다. 코드에 없으면 '빠짐'.
3. **박아 둔 값.** 코드 조건에 특정 ID·이름·날짜가 그대로 들어간 곳을 찾는다(`grep -nE '== ?["\x27][A-Z]-?[0-9]'`, 날짜·월 `20[0-9]{2}[-,(]`·`[0-9]+월` 등). 같은 검색을 `data/` 같은 원본에 돌려 그 값이 실제로 있는지(1 이상) 대조해, 0건이 '없어서'인지 '검색이 틀려서'인지 가른다. 규칙으로 바꿀 수 있으면 고칠 것 목록에.
4. **확인 안 된 것.** AGENTS.md '확인 안 된 것' 중 코드가 이미 한쪽으로 정해 버린 곳을 찾는다. 사용자가 정하지 않은 결정은 숨기지 않는다.
5. 발견마다 근거(규칙 번호·파일:줄)를 단다. 고치는 방법은 한 줄 안내만.

마지막: 고칠 것 목록(빨리 끝나는 것부터). 없으면 `고칠 것 없음`. 사용자가 '확인 안 된 것'을 그 자리에서 정하면 그 줄 끝에 `→ 사용자 결정 HH:MM (요청자 미확인)` 을 단다. 코드를 고쳐야 하는 것은 PLAN.md 에 새 단계로 넣자고 제안하고, 사용자가 받으면 `$구현 N` 으로 처리한다. 점검 스크립트가 '고칠 것 없음'이어도 이 검사에서 나온 것이 우선이다.

시각(HH:MM)은 `date +%H:%M` 으로 찍는다.
