# 작업 기록

README 가 기록 문서 이름을 정했으면 그 파일에. 아니면 `NOTES.md`. 덧붙이기만 하고 지우지 않는다. 틀린 기록은 지우지 말고 `(정정 HH:MM: …)` 을 단다.

```
## [HH:MM] 한 줄 제목
- 결정: 무엇을 / 왜(출처: 요청자 HH:MM, 커밋, 파일:줄) / 기각한 것과 이유
- 트러블슈팅: 증상 → 원인(잰 것) → 고친 것 → 다시 확인한 결과
- 확인: 명령 → 결과 (사용자가 직접 본 것은 '직접')
```

쓰고 나서 터미널에 짧게:
- **설명해야 할 지점 3개.** 이 결과물에서 누가 "왜 이렇게 했어요?" 라고 물을 곳. 짧은 명사구로.
- **약점 3개.** 틀릴 수 있는 곳 → 그러면 무슨 일이 → 어떻게 확인할지.

문장을 대신 다듬어 주지 않는다. 사용자가 자기 말로 말할 수 있게 재료만.
